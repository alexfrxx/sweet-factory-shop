# 🍰 Sweet Factory

Sweet Factory is a responsive dessert shop website built with modern web
technologies. The project presents a clean and engaging interface for browsing
sweet products and interacting with different sections of the website.

🌐 **Live Demo:** https://alexfrxx.github.io/sweet-factory-shop/

## ✨ Features

- 📱 Fully responsive layout
- 🍰 Dessert catalog
- 🔄 REST API integration
- ⚡ Fast development and production builds with Vite
- 🎨 CSS animations and transitions
- 🖼️ SVG graphics and custom assets
- 💬 Customer reviews
- ❓ Frequently Asked Questions
- 📝 Contact form
- 📐 Mobile, tablet, and desktop support

## 🛠️ Technologies

- **HTML5**
- **CSS3**
- **JavaScript (ES6+)**
- **Vite**
- **Axios**
- **REST API**
- **SVG**
- **Responsive Web Design**

## 🚀 Getting Started

### 1. Clone the repository

```bash
git clone https://github.com/alexfrxx/sweet-factory-shop.git
```

### 2. Navigate to the project

```bash
cd sweet-factory-shop
```

### 3. Install dependencies

```bash
npm install
```

### 4. Start the development server

```bash
npm run dev
```

The application will be available at the local URL provided by Vite.

## 📦 Available Scripts

### Development

```bash
npm run dev
```

Starts the development server.

### Production Build

```bash
npm run build
```

Creates an optimized production build.

### Preview

```bash
npm run preview
```

Runs the production build locally for preview.
